La sécurité domine l'actualité d'hier : un agent IA a mené seul une intrusion complète, et Signal se protège des assistants intégrés aux systèmes. Côté outils, PHP 8.6 durcit ses sessions et Valkey revoit ses ensembles triés.

## L'essentiel

::: details **Agents IA et zero-day** : selon Amazon, des agents IA liés à la Chine ont trouvé et exploité seuls une faille inconnue, jusqu'à un accès root.
L'équipe de renseignement sur les menaces d'Amazon a publié un rapport le 20 novembre. Il décrit une campagne lancée le 8 septembre contre des universités d'Asie de l'Est. Amazon parle d'acteurs « liés à la Chine » : consignes en chinois simplifié, horaires calés sur l'heure de Chine.

Les agents, lancés avec Cairn, un outil libre de test d'intrusion, ont d'abord échoué :

- environ 16 heures et 148 actions contre une base Redis ;
- une tentative sur un serveur de calcul avec 80 vrais noms d'utilisateurs.

Ils ont ensuite visé MONAI Label, un logiciel libre d'imagerie médicale. Une traversée de chemin (des `../` dans un nom de fichier envoyé) a fonctionné. Selon Amazon, environ 11 minutes séparent la découverte du point d'envoi de la première écriture de fichier arbitraire, avant la prise de contrôle root.

Un humain est intervenu ponctuellement, par exemple pour fournir l'accès à un second réseau. La part exacte du travail humain reste inconnue. Les détails viennent d'une source unique, [The Register](https://www.theregister.com/security/2026/11/20/china-attackers-deployed-ai-agents-that-autonomously-found-and-exploited-a-0-day-to-take-over-a-university-server/5311382), qui cite le [rapport d'Amazon](https://aws.amazon.com/blogs/security/chinese-nexus-actors-cairn-ai-agents-found-a-zero-day-on-their-own/). Le correctif figure dans l'[avis de sécurité MONAI Label](https://github.com/Project-MONAI/MONAILabel/security/advisories/GHSA-qc22-rmgc-vg94).

> **Pour vous :** réduisez tout nom de fichier reçu à son nom de base, ou remplacez-le par un nom généré côté serveur.
:::

::: details **Signal contre les assistants IA** : Signal bloque désormais les captures d'écran pour empêcher Siri et Gemini de lire les messages affichés.
Le chiffrement de bout en bout protège le trajet des messages, pas l'écran. Siri et Gemini lisent le texte affiché par OCR, et ce texte peut partir vers les serveurs d'Apple ou de Google.

Le 20 novembre, la présidente de Signal, Meredith Whittaker, a annoncé de nouvelles protections :

- iOS 27 : captures bloquées dans l'application et réglage « Bloquer Siri AI » ;
- Android : « sécurité d'écran » activée automatiquement quand un assistant tente de lire l'écran ;
- Mac : pas de blocage fiable, Signal conseille de l'exclure dans les réglages de Siri.

Signal avait fait de même en 2025 contre Recall, sur Windows 11. L'entreprise parle de menace « existentielle ». Elle demande à Apple, Google et Microsoft un moyen documenté pour qu'une application refuse l'accès des IA à ses données.

Limite reconnue : bloquer les captures n'empêche pas d'autres accès, par exemple via les fichiers stockés. Selon The Register, macOS 27.3 ajoute des autorisations plus fines, mais surtout pour les programmes tiers. Sources : [blog de Signal](https://signal.org/blog/protecting-your-privacy/), [The Register](https://www.theregister.com/security/2026/11/20/signal-slams-door-on-prying-ai-agents-to-protect-privacy/5311466).

> **Pour vous :** si votre application mobile affiche des données sensibles, étudiez le blocage des captures, par exemple l'option `FLAG_SECURE` d'une fenêtre Android.
:::

::: details **PHP 8.6** : sorti le 19 novembre, PHP 8.6 active par défaut le mode strict, HttpOnly et SameSite=Lax pour les cookies de session.
PHP 8.6 arrive après une série de failles graves. Selon la [RFC](https://wiki.php.net/rfc/session_security_defaults), trois réglages de session changent de valeur par défaut :

- `session.use_strict_mode` passe à 1 : PHP refuse un identifiant qu'il n'a pas créé, ce qui bloque la fixation de session ;
- HttpOnly passe à 1 : le JavaScript de la page ne peut plus lire le cookie ;
- SameSite=Lax : le cookie n'accompagne plus les formulaires envoyés depuis un autre site, ce qui freine le CSRF.

La version devient aussi plus stricte avec les octets nuls dans les chaînes. Elle ajoute `clamp()`, une classe `Duration` et une API native de polling réseau.

Ces valeurs ne s'appliquent que si rien d'autre ne les fixe : un ancien `php.ini` avec `session.use_strict_mode = 0` garde son comportement. SameSite peut casser les flux entre domaines, comme le paiement ou la connexion unique. Ces protections ne bloquent pas l'exécution de code à distance. Sources : [LWN](https://lwn.net/Articles/1108555/), [The Register](https://www.theregister.com/devops/2026/11/20/php-86-things-are-gonna-get-a-lot-more-strict-around-here/5311486).

> **Pour vous :** lancez `php -i | grep session` ou ouvrez votre `php.ini` pour vérifier ces trois valeurs.
:::

::: details **Valkey 9.2** : les grands ensembles triés passent d'une skiplist à un arbre B+, avec un surcoût mémoire réduit jusqu'à 43 %.
Le [blog Valkey](https://valkey.io/blog/from-skiplist-to-b+tree/) décrit le changement le 16 novembre. L'arbre B+ maison range jusqu'à 61 éléments par feuille de 512 octets. Les données sont contiguës, alors que la skiplist dispersait chaque élément en mémoire.

Mémoire, pour 5 millions d'éléments :

- insertion ordonnée : de 50,3 à 28,5 octets de surcoût par élément ;
- soit −43 %, environ 109 Mo gagnés ;
- insertion aléatoire : −36 %.

Vitesse :

- mise à jour d'un score (`ZADD`) : +105 % ;
- calcul du rang (`ZRANK`) : +19 %.

Ces gains portent sur la structure de tri, pas sur la mémoire totale. Les mesures viennent de l'équipe Valkey, sur une seule machine. Côté utilisateur, seule `OBJECT ENCODING` change : elle affiche `btree`.

Les [notes de la 9.2.0-rc2](https://newreleases.io/project/github/valkey-io/valkey/release/9.2.0-rc2) corrigent déjà une fuite mémoire dans l'arbre. [Dragonfly](https://www.dragonflydb.io/blog/dragonfly-new-sorted-set) avait fait ce choix en 2024.

> **Pour vous :** si vous utilisez de grands ensembles triés, mesurez la 9.2.0-rc2 sur vos propres données plutôt que de vous fier aux seuls chiffres de l'éditeur.
:::

## Les autres sujets

L'IA traverse la plupart des autres sujets : une preuve mathématique vérifiée par Lean, deux modèles ouverts, des lunettes caméra jugées dangereuses et une pénurie de circuits imprimés. La sécurité reste présente avec le vol de clés SSH sur Fugaku et un contournement de l'écran de connexion de Windows 11. Côté outils, LLVM clôt son changement de licence. Le jeu vidéo oppose le lancement record de GTA VI aux difficultés d'Ubisoft.

### IA et mathématiques

::: details **Hypothèse de Riemann** : une preuve obtenue avec Claude compile dans Lean, sans version lisible par un humain.
Le 20 novembre, Levent Alpöge, mathématicien employé d'Anthropic, a annoncé une preuve de l'hypothèse généralisée ([annonce PDF](https://alpo.ge/remark.pdf)). Elle compte environ 17,4 millions de lignes de Lean, selon [Scott Aaronson](https://scottaaronson.blog/?p=10344), qui parie qu'elle tiendra. Plusieurs personnes, dont Andrew Sutherland (MIT), confirment qu'elle compile. [Terence Tao](https://terrytao.wordpress.com/2026/11/20/unforced-euler-singularity-unforced-navier-stokes-singularity-and-the-generalized-riemann-hypothesis/) parle « des tout premiers jours », et Lean a déjà eu des bugs. L'auteur travaillant pour l'éditeur de l'IA utilisée, la vérification indépendante compte d'autant plus. Le même jour, Alessandro Masullo (Stanford) a publié un brouillon humain de 940 pages, non vérifié ([TechCrunch](https://techcrunch.com/2026/11/20/ai-claimed-a-solution-to-the-167-year-old-riemann-hypothesis-and-a-human-did-too/)).
:::

::: details **Inkling 2 Mini** : un modèle ouvert qui rejoue trois fois ses couches centrales.
Publié le 20 novembre par [Thinking Machines Lab](https://thinkingmachines.ai/news/inkling-2-mini/), il compte 26,4 milliards de paramètres. Seuls 3,4 milliards sont actifs par mot, selon le principe du mélange d'experts. Ses couches du milieu sont rejouées trois fois pour « réfléchir » plus sans grossir. Il tient dans environ 20 Go et tourne avec Ollama ou llama.cpp. L'éditeur le présente comme le meilleur modèle ouvert de moins de 100 milliards de paramètres en programmation. Il est plus faible en conversation longue.
:::

::: details **Modèle auto-modifiant** : une prépublication décrit un modèle qui réécrit ses propres poids.
Mise en ligne le 16 novembre sur [arXiv](https://arxiv.org/abs/2611.21885), l'étude n'est pas relue par des pairs. Un modèle ouvert de 27 milliards de paramètres reçoit ses poids, ses réponses notées et la possibilité de se relancer. Il localise les parties responsables de ses erreurs, les réécrit et ne garde que les modifications utiles. Les auteurs annoncent un gain de 6,6 points sur des problèmes inédits. La capacité n'apparaît que sur les plus gros modèles et reste à confirmer.
:::

### Sécurité et vie privée

::: details **Fugaku** : le RIKEN confirme le vol de 430 clés SSH.
Le bilan du 20 novembre porte sur l'intrusion dans les supercalculateurs Fugaku et RIKYU, annoncée le 16. Les clés étaient stockées par des utilisateurs dans leur dossier personnel. Parmi elles, 233 n'avaient pas de phrase secrète. Certaines ont déjà servi à se connecter ailleurs. Les données de 4 222 utilisateurs sont touchées, et Fugaku reste à l'arrêt sans date de retour. Source : [HPCwire](https://www.hpcwire.com/off-the-wire/riken-confirms-theft-of-430-private-keys-in-fugaku-and-rikyu-intrusion/).
:::

::: details **Windows 11 et le Narrateur** : FastUnlock ouvre une session sans mot de passe, avec un accès physique.
Le chercheur Abdelhamid Naceri part de l'écran « code PIN oublié » et lance le Narrateur. Il atteint les Paramètres par une fenêtre invisible, puis exécute un programme depuis une clé USB. L'attaque fonctionne sur un Windows 11 à jour, sans correctif disponible. Parade indiquée : un code PIN au démarrage de BitLocker, et l'extinction ou la veille prolongée en cas d'absence. Source : [Next](https://next.ink/268851/windows-11-une-faille-permet-de-contourner-lecran-de-connexion-grace-au-narrateur/).
:::

::: details **Lunettes caméra à IA** : l'autorité néerlandaise des données déconseille leur achat.
L'AP a testé six modèles, sans citer les marques, et les juge dangereuses pour les porteurs comme les passants :

- erreurs sur des notices de médicaments et des alertes météo ;
- secours déclarés prévenus à tort pendant une simulation de massage cardiaque ;
- voyants d'enregistrement faibles ou masquables ;
- connexion possible de tiers aux lunettes ;
- données envoyées surtout hors de l'UE.

Ce n'est pas une interdiction. Sources : [The Register](https://www.theregister.com/security/2026/11/20/dutch-data-watchdog-highlights-safety-issues-with-ai-glasses/5311345), [AP](https://autoriteitpersoonsgegevens.nl/actueel/ap-raadt-aankoop-ai-camerabrillen-af-ernstige-risicos-voor-gebruikers-en-omstanders), [avis de septembre](https://www.dutchitchannel.nl/news/760659/ap-verbiedt-het-gebruik-van-camerabrillen-in-huisregels).
:::

::: details **CJUE et gratuité** : pour une avocate générale, payer avec ses données n'est pas un service gratuit.
L'affaire vise le slogan « c'est gratuit et ça le restera », affiché par Facebook en Allemagne jusqu'en 2019. Une association de consommateurs a attaqué Meta pour publicité trompeuse. L'avocate générale Laila Medina estime que fournir ses données et accepter leur usage publicitaire constitue un paiement. Son avis ne lie pas la Cour, qui le suit souvent. Source : [Next](https://next.ink/268491/pour-une-conseillere-de-la-cjue-facebook-nest-plus-gratuit-car-on-paie-avec-ses-donnees/).
:::

### Outils et systèmes

::: details **Licence de LLVM** : le passage à Apache 2.0 avec exception LLVM se termine après huit ans.
Kristof Beyls l'a annoncé le 20 novembre sur le [forum LLVM](https://discourse.llvm.org/t/wrapping-up-llvms-relicensing-effort/92906). Le nouveau code est accepté sous cette licence depuis janvier 2019.

- Signataires : plus de 1 300 personnes et environ 100 entreprises.
- Plus de 99,5 % du code historique est relicencié, trop court pour être protégé ou retiré.

Le reste garde sa licence d'origine. Selon LLVM, une licence unique simplifie l'analyse juridique et la nomenclature logicielle. Contexte : [LWN](https://lwn.net/Articles/1108818/).
:::

::: details **Règle de l'orphelin en Rust** : un article détaille la règle et une astuce pour la contourner.
La règle interdit d'implémenter un trait d'une bibliothèque pour un type d'une autre bibliothèque. Sans elle, deux bibliothèques pourraient définir des implémentations concurrentes. L'[article d'edvong.com](https://edvong.com/bypass-orphan-rule/), publié le 16 novembre, rappelle la solution du newtype. Il propose ensuite d'ajouter au trait un paramètre générique rempli par un type marqueur local. Une lecture utile face à l'erreur E0117.
:::

::: details **Ubuntu Core Desktop** : Canonical vise une version immuable finale avec Ubuntu 28.04.
Le système principal y est en lecture seule. Les mises à jour sont atomiques, avec retour arrière en cas d'échec, et reposent sur des snaps. Canonical espère en faire le téléchargement par défaut avec la version 30.04, sans retirer l'Ubuntu classique. Une version de bureau avait déjà été promise en 2023, sans être livrée. Source : [The Register](https://www.theregister.com/os-platforms/2026/11/20/ubuntu-core-desktop-targets-2804-debut-with-default-status-in-its-sights/5310837).
:::

::: details **Lanceur Epic sur Linux** : l'aperçu est pris en charge sur Ubuntu, Fedora et Debian.
La version 0.120.0 vise Ubuntu 22.04 ou plus récent, Fedora 43 et Debian 12. Elle est livrée en paquet .deb et en AppImage, et tourne nativement. Beaucoup de jeux restent prévus pour Windows et demanderont une couche de compatibilité comme Proton. Source : [GamingOnLinux](https://www.gamingonlinux.com/2026/11/epic-games-launcher-preview-now-supported-across-fedora-ubuntu-and-debian/).
:::

### Matériel, calcul et science

::: details **Pénurie de circuits imprimés** : les serveurs d'IA saturent la production de cartes électroniques.
La Global Electronics Association compare la situation à la pénurie de puces de 2021. Une carte de serveur d'IA compte 40 à 60 couches, contre environ 12 pour un PC.

- Commandes nord-américaines sur neuf mois : +56 %.
- Livraisons sur la même période : +13 %.
- Délai du stratifié FR-4 : de 2-3 à 6-8 semaines.
- Cuivre sur un an : +37 %.

Automobile, médical et industrie passent après l'IA, sans amélioration nette attendue avant mi-2028. Source unique : [The Register](https://www.theregister.com/systems/2026/11/20/ai-boom-threatens-circuit-board-crunch-to-rival-pandemic-era-chip-shortage/5311335), d'après une association professionnelle.
:::

::: details **M5Stack Chain Captain** : un contrôleur ESP32-S3 qui pilote des modules chaînés.
Le boîtier mesure 56 × 40 mm. Il intègre un écran couleur, un haut-parleur, un micro, un capteur de mouvement, l'infrarouge en émission et réception, et une batterie. Les modules sont reliés en chaîne par un seul câble UART, chacun relayant les messages au suivant. Le contrôleur coûte environ 35 $. Il se programme avec Arduino, UIFlow2 ou ESP-IDF. Source : [CNX Software](https://www.cnx-software.com/2026/11/20/m5stack-chain-captain-an-esp32-s3-multifunctional-controller-with-1-54-inch-color-display-audio-motion-sensing-ir-tx-rx/).
:::

::: details **Prix Gordon Bell 2026** : le FeMoco, réputé quantique, calculé sur supercalculateur classique.
Le prix a été remis le 19 novembre à la conférence SC26 de Chicago, à une équipe chinoise. Chiffres annoncés :

- 20 480 nœuds de la machine LineShine ;
- 1,456 exaflop/s en double précision, soit 58,9 % du maximum théorique ;
- 5,6 exaflop/s en précision mixte.

Une équipe avait déjà montré en janvier un calcul classique précis du FeMoco ([arXiv](https://arxiv.org/abs/2601.04621), [Garnet Chan](https://quantumfrontiers.com/2026/03/12/the-femo-cofactor-and-classical-and-quantum-computing/)). Source unique pour les chiffres : [HPCwire](https://www.hpcwire.com/off-the-wire/chinese-team-wins-2026-acm-gordon-bell-prize-for-exascale-quantum-chemistry/).
:::

::: details **Alice & Bob** : objectif de 200 qubits logiques en 2030.
Les « qubits de chat » de la start-up française bloquent un type d'erreur dès le matériel. Feuille de route présentée le 18 novembre :

- 2028 : 6 qubits logiques ;
- 2030 : 200, le double de l'objectif précédent ;
- 2032 : 1 024.

## Analyse

L'attaque contre MONAI Label repose sur une faille banale, la traversée de chemin, trouvée par un agent qui a persisté malgré des échecs répétés. La validation des entrées reste donc la première ligne de défense. Reste à voir combien d'attaques similaires passent inaperçues.

Sur mobile, Signal souligne qu'aucun mécanisme documenté ne permet à une application de refuser l'accès des assistants système. NEXUS, l'assistant Android en React Native de Melchior, manipule des données personnelles comme les repas et le poids : c'est le type d'application concerné par cette demande.

PHP 8.6 et Valkey 9.2 rappellent que les valeurs par défaut et la disposition en mémoire comptent autant que les nouveautés visibles. Le premier ne protège que les configurations qui n'imposent rien. Le second n'a été mesuré que par son équipe, sur une seule machine.
