An injection flaw in an IRC server exploited within a day, a 1991 compiler rebuilt down to the byte and an AI-produced mathematical proof lead yesterday's news. Security also accounts for a large share of the other stories.

## Key points

::: details **UnrealIRCd** : an injection flaw rated 8.6 out of 10 has been exploited since the day after its fix, released on 7 November.
CVE-2026-114713 affects UnrealIRCd, one of the most widely used open-source IRC servers.

- Severity: 8.6 out of 10.
- Affected versions: 6.0.0 up to, but not including, 6.2.7.1.
- Fix: 7 November, with attack attempts starting the next day according to [The Hacker News](https://thehackernews.com/2026/11/attackers-exploit-unrealircd-flaw-that.html).
- CISA KEV catalog: added on 13 November, with federal agencies required to patch by 16 November ([CISA alert](https://www.cisa.gov/news-events/alerts/2026/11/13/cisa-adds-two-known-exploited-vulnerabilities-catalog)).

The module handling IRCv3 labels copies those tags into replies without escaping them. On a network of two or more servers, any user can slip server-to-server commands into a label. Other servers then execute them with server or IRCOp privileges.

The maintainer, Bram Matthys (Syzop), calls it "the most critical issue found in UnrealIRCd in 15 years" and reports ongoing attacks. Their details have not been published. A workaround filter is available for networks that cannot upgrade.

> **For you:** if you run an UnrealIRCd 6 network, upgrade to 6.2.7.1 or apply the maintainer's filter, and check that your own code escapes any external data echoed back into a message.
:::

::: details **Borland C++ 2.0** : the 1991 DOS compiler has been rebuilt as source code that produces the exact original binary.
The "borland-reborn" project, published by Abedegno, provides source code that compiles back into the original BCC.EXE. The final proof: both files have identical SHA-256 hashes.

The method is matching decompilation, described in the [repository's technical document](https://github.com/abedegno/borland-reborn/blob/main/docs/HOW-IT-WORKS.md):

- recover the exact toolchain: TASM 2.51, TLINK 4.0 and the original options;
- discover that 29 runtime library modules actually came from Turbo C 2.01;
- split the program into segments and overlays, a legacy of DOS's 640 KB limit;
- rebuild each file in C or assembly, with no hand-patched bytes;
- then make the code readable (around 300 field names, 40 structures), re-checking after each step.

According to [Hackaday](https://hackaday.com/2026/11/13/borland-c-2-0-compiler-source-reconstructed/), the work relied on Exhume, the author's tool built on Claude Code. The repository document does not mention AI. The legal status of this reconstructed code is not addressed, while the original software remains protected.

> **For you:** to see why this is hard, compile a small C function on [Compiler Explorer](http://godbolt.org/) and watch how the assembly changes with an option such as -O2.
:::

::: details **FaceStealer** : according to the FBI, fake North Korean video calls led to more than $400 million in stolen cryptocurrency.
The FBI detailed this campaign, attributed to North Korea-linked hackers, on 13 November. The figures come from a single source, [The Hacker News](https://thehackernews.com/2026/11/fbi-says-north-korean-hackers-stole.html).

How it works:

- a video meeting invite arrives from a contact's compromised account;
- the victim sees a recording of a previous victim, sometimes deepfakes of industry figures;
- a fake audio problem prompts them to "fix" it with a booby-trapped command (the ClickFix technique);
- their webcam is recorded and later used to lure their own contacts.

Reported figures:

- more than $400 million stolen over 18 months;
- more than 900 webcam recordings seized along with the cloud infrastructure;
- 677 targets in 58 countries counted by Arctic Wolf, over 80% of them founders or executives.

The attackers also target open-source maintainers in order to compromise widely used libraries. Separately, the US Department of Justice announced the seizure of more than $1.2 billion linked to the Binance theft.

> **For you:** never paste into a terminal a command handed to you during a call, and run technical interview exercises in a disposable virtual machine.
:::

::: details **Yang-Mills** : an expert panel finds OpenAI's proof does construct the theory, but proves neither uniqueness nor the mass gap.
The Yang-Mills millennium problem has two halves: proving the theory exists (Wightman axioms) and proving the "mass gap". In late October, OpenAI announced proofs produced by its models ([Interesting Engineering](https://interestingengineering.com/ai-robotics/openai-proofs-math-computing-physics)).

Timeline:

- 28 October: submission on "pure" Yang-Mills to a panel chaired by David Gross, 2004 Nobel laureate;
- 4 November: a second submission, on QCD, still under review;
- 10 November: the panel's first opinion and release of the [Lean code](https://github.com/yang-mills-group/YM).

The verdict: the submission builds a theory satisfying the Wightman axioms, starting from a lattice version whose spacing is progressively refined. It proves neither uniqueness in infinite volume nor the mass gap.

According to an [analysis on the Hugging Face blog](https://huggingface.co/blog/dlouapre/yang-mills-openai), the experts say they do not yet fully understand the proof. They rely on the Lean code rather than the 1,147-page manuscript. The panel stresses that publishing a submission does not mean validating it.

> **For you:** to understand what a proof assistant checks, Lean's "Natural Number Game" tutorial runs free in the browser.
:::

## Other news

Security still dominates: SMS hijacking inside mobile networks, wiped firewalls and a booby-trapped software update at a drone maker. ### Security

::: details **SilentAir** : a state actor hijacks SMS and calls through equipment inside Asian mobile operators.
[Enea](https://www.enea.com/insights/the-enemy-within-tracking-liminal-panda-and-silentair-through-mobile-networks/) describes a group sending fake "UpdateLocation" messages to reroute calls and SMS. Two-factor codes followed some of the hijacks. Interception makes up 18.3% of its attacks, versus 2.1% for a typical surveillance vendor. Silent SMS mainly target Taiwan. Enea sees a state actor with "high confidence" and links it to China with "low confidence" ([The Hacker News](https://thehackernews.com/2026/11/silentair-hijacks-asian-telecom.html)).
:::

::: details **Check Point** : unpatched firewalls received a backdoor, then a wiper.
Attacks began in Israel on 30 October, then spread to several countries on 2 November. A remote access portal flaw, then CVE-2026-123039 (rated 7.8), gave root access. Around two dozen customers are affected, although the fix had been out a week earlier ([The Hacker News](https://thehackernews.com/2026/11/hackers-exploit-php2shell-flaws-in.html)). CISA added the flaw to its [KEV catalog](https://www.cisa.gov/news-events/alerts/2026/11/13/cisa-adds-two-known-exploited-vulnerabilities-catalog) on 13 November.
:::

::: details **Quantum Systems** : a booby-trapped update of its QBase software reached the German army.
According to Der Spiegel, cited by [The Register](https://www.theregister.com/security/2026/11/13/quantum-systems-drones-back-in-the-air-after-malware-scare/5309658), the update to this flight-planning software hit military servers and other customers. The drones themselves reportedly were not infected. The German army paused flights as a precaution, and the company says everything is flying again. Who tampered with the update, and how, remains unknown.
:::

::: details **Facial recognition** : the UK police inspectorate finds police use poorly regulated and at risk of wrongful arrests.
The inspectorate calls oversight of retrospective facial recognition "fragmented and underdeveloped". There is no dedicated law. Investigators treated a software match as evidence, and photos that should have been deleted were kept. The inspectorate wants a national legal framework, while Big Brother Watch calls for an end to the practice ([The Register](https://www.theregister.com/security/2026/11/13/brit-police-watchdog-says-cops-use-of-facial-recog-risks-wrongful-arrests/5309379)).
:::

### Systems, embedded and learning

::: details **Wine 11.22** : ASLR and AVX in x86 emulation on ARM64 in this development release.
Released on 14 November, it leads up to Wine 12, expected in early 2027. It adds address space layout randomisation, Unicode CLDR 49 and MSXML improvements. [GamingOnLinux](https://www.gamingonlinux.com/2026/11/wine-11-22-brings-improved-support-for-arm64-msxml-and-address-space-randomisation/), the only available source, lists 34 bug fixes, including Notepad++ and Guild Wars 2. Proton will only benefit later.
:::

::: details **XRAID** : RAID built into XFS, designed for zoned drives.
Christoph Hellwig publishes the project after a year and a half of work. It supports zero to two parity drives. Its authors claim writes up to 20 times faster than mdraid, without independent testing. The project is far from kernel inclusion and is looking for testers ([LWN](https://lwn.net/Articles/1107473/)).
:::

::: details **CO₂ sensors** : an ESPHome configuration that makes failures visible instead of silent.
William Collis uses a Sensirion SCD30 and an ESP32-C3 connected to Home Assistant. When a sensor failed, the display kept the last valid reading, indistinguishable from a normal one. His modified configuration flags the failure, with a warning LED. The principle applies to any system: fail visibly ([Hackaday](https://hackaday.com/2026/11/14/making-co%e2%82%82-sensors-fail-visibly-not-silently/)).
:::

::: details **DeviceTree** : a hands-on introduction to describing hardware to the Linux kernel.
On boards like the Raspberry Pi, hardware often cannot be probed. A .dts file, compiled into .dtb, describes it to the kernel at boot. Overlays add a sensor or display. Arya Voronova warns that AI-generated tutorials sometimes invent properties ([Hackaday](https://hackaday.com/2026/11/10/devicetree-for-hackers-intro/)).
:::

::: details **PostScript interpreter** : a tutorial on writing a small stack-based interpreter in JavaScript.
PostScript uses reverse Polish notation: 3 4 add instead of 3 + 4. The [beyondloom article](https://beyondloom.com/blog/postscript.html) builds the interpreter with a value stack and a dictionary stack. [Hackaday](https://hackaday.com/2026/11/14/rpn-loved-honk-if-or-write-your-own-postscript-interpreter/) calls it "tiny and comprehensible". A good entry point for understanding how a language works.
:::

## Analysis

UnrealIRCd and SilentAir rely on the same weakness: full trust between servers or between operators, which turns unescaped data or a forged message into a legitimate command. FaceStealer and QBase exploit another kind of trust, in a known contact or a supplier. The observed windows are short: attacks the day after the UnrealIRCd fix, and a week after the Check Point patch.

Borland C++ 2.0 and Yang-Mills share a methodological point: the value of the result rests on mechanical verification, a SHA-256 hash in one case and the Lean checker in the other. It remains to be seen whether review by other mathematicians will confirm the proof, and how the legal status of the Borland code will be handled. On the Linux side, Wine, XRAID and SteamOS are still development or test releases whose stability is worth watching.
