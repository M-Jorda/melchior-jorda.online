Security dominated November 19, with critical fixes for PHP and an official Microsoft Python package compromised. PostgreSQL 19 also makes it possible to clean up a table without locking it.

## Key points

::: details **PHP** : on November 19, the PHP team fixed at least eight serious flaws, including phpAfterShell, which involves session files.
Releases published on November 19:

- 8.2.36, 8.3.37, 8.4.28 and 8.5.13;
- the new major version 8.6.0.

[The Hacker News](https://thehackernews.com/2026/11/php-fixes-7-critical-flaws-including.html) lists eight serious CVEs. Seven are rated 9.2 out of 10 (CVSS v4). According to [Next](https://next.ink/268437/lequipe-php-previent-de-nouveaux-correctifs-critiques-pour-ce-19-novembre/), each release fixes around twenty flaws in total.

The main flaws:

- **phpAfterShell** (CVE-2026-126714), found by Depthfirst: a worker killed while writing a session file leaves a mix of old and new data. A crafted object can then be deserialized on the next request ([detailed explanation](https://thehackernews.com/2026/11/phpaftershell-explained-how-hackers.html)). The researchers needed 11 attempts in their test.
- Several use-after-free bugs, one of them exploitable without an account.
- A flaw involving persistent connections between nginx, Apache or HAProxy and PHP.

Almost all of them require a non-standard configuration. No real-world attack has been reported, and CERT-FR considers exploitation unlikely. Still, this is the second wave in a month, after PHP2Shell in October, whose fix had not solved the underlying problem.

Note: the new releases disable session upload progress by default. This can break an upload progress bar.

> **For you:** check your version with `php -v`, update and restart PHP-FPM, and set `session.upload_progress.enabled` to 0 if you do not use the feature.
:::

::: details **Microsoft agent-framework** : two booby-trapped releases of the official Python library for AI agents stole secrets through PyPI.
On November 17, versions 1.26.1 and 1.26.2 were published half an hour apart from Microsoft's official PyPI account. The library is downloaded nearly 200,000 times a month. [The Register](https://www.theregister.com/security/2026/11/18/microsofts-official-python-agent-framework-hijacked-to-distribute-malware/5310858) mentions stolen admin access to Microsoft's GitHub organization.

How it worked, as described by [Wiz](https://www.wiz.io/blog/malicious-version-of-microsofts-agent-framework-published-to-pypi) and [OX Security](https://www.ox.security/blog/breaking-hijacked-releases-of-microsofts-official-agent-framework-steals-azure-and-ci-credentials/):

- code ran at Python startup through a `.pth` file, with no import needed;
- it installed the genuine 1.26.0 so everything kept working;
- it collected environment variables and Azure, Git, Docker and Hugging Face credentials;
- it requested fresh tokens from GitHub Actions and Azure DevOps;
- data was sent to webhook.site.

The releases have been quarantined. Microsoft made some repositories private during the investigation. It is still unknown how many machines, CI runners in particular, installed them.

> **For you:** if version 1.26.1 or 1.26.2 was installed, remove it and rotate every key on the machine, then pin your dependencies with hashes (`pip install --require-hashes`, uv or poetry).
:::

::: details **PostgreSQL 19** : released on November 19, it compacts a table without blocking reads and writes, thanks to REPACK CONCURRENTLY.
The main new features, according to the [official announcement](https://www.postgresql.org/message-id/attachment/208469/release.en.md) and [LWN](https://lwn.net/Articles/1108561/):

- **REPACK (CONCURRENTLY)** reduces bloat without locking the table, except for a brief moment at the end. It replaces VACUUM FULL and CLUSTER, which remain available.
- **pg_plan_advice** pins a query plan when the planner starts picking a slower one.
- **INSERT ... ON CONFLICT DO SELECT** fetches a row or creates it in a single round trip.
- **WAIT FOR LSN** guarantees that a read on a replica sees what was just written.
- Foreign key checks are faster: bulk inserts are almost twice as fast in the project's tests.
- JIT compilation is now off by default, because it was triggered poorly.

[Snowflake](https://www.snowflake.com/en/blog/engineering/postgres-19-repack-table-bloat/) details the limits of REPACK. It requires a primary key. A very old transaction may also see the table as empty during the operation.

Version 14 has been out of support since the previous week.

> **For you:** try these features in a `postgres:19` Docker container, and check that your tables have a primary key before planning REPACK CONCURRENTLY.
:::

## Other news

Security still leads: a vCenter flaw exploited as a zero-day, a hardware attack on the TPM retry counter and a cyberattack on the European Commission. In AI, Anthropic went public, while Meta's Muse agent reportedly exposed private data. Hardware news includes the ESP32-S31 and an open TPM for Raspberry Pi. Gaming broke records, for traffic with GTA VI and for releases on Steam.

### Security

::: details **VMware vCenter and KVM** : a vCenter flaw rated 9.8 had been exploited since September, before any fix.
Broadcom fixed CVE-2026-123890 on November 19. Simple network access to vCenter is enough to bypass authentication in its directory service. According to Google, an espionage group suspected of ties to China had exploited it since early September ([The Hacker News](https://thehackernews.com/2026/11/critical-vmware-vcenter-flaw-cvss-98.html)). Versions 8.0, 9.0 and 9.1 are affected, with no official workaround. On Linux, CVE-2026-99312 (5.5) lets a VM crash the host, only on AMD with nested virtualization ([The Register](https://www.theregister.com/security/2026/11/20/flaws-in-vmware-and-kvm-need-attention-if-you-have-time-while-fixing-java-php-and-everything-else/5311193)).
:::

::: details **TPM and Windows PINs** : researchers reset the TPM retry counter to brute-force a PIN.
The Technical University of Berlin targeted firmware TPMs (fTPM), which store their state in the flash chip. The PC must be opened.

- On AMD, the processor does not check that the monotonic counter (RPMC) actually increased.
- On Winbond flash chips, a voltage glitch leaks the counter key.

A 4-digit Hello PIN fell in 57 minutes. AMD acknowledges the flaw (CVE-2026-43613), and Microsoft will recommend at least 6 digits ([The Hacker News](https://thehackernews.com/2026/11/flash-chip-attack-bypasses-tpm-lockout.html), [arXiv](https://arxiv.org/abs/2611.18126)).
:::

::: details **European Commission** : a cyberattack shut down internal services; the use of the Artex tool is unconfirmed.
Revealed by Politico on November 19, the attack was detected on October 22, according to [Next](https://next.ink/268532/cyberattaque-a-la-commission-europeenne-une-plateforme-agentique-de-pentest-mise-en-cause/). Payroll and medical reimbursement services were shut down as a precaution. A Politico source points to Artex, an AI-driven pentest platform pulled from GitHub but still circulating as copies. The Commission does not name Artex and says it has no evidence of staff data leaks. The FBI counted more than 1,600 exposed Artex consoles ([The Register](https://www.theregister.com/cyber-crime/2026/11/19/european-commission-scrambles-to-contain-ai-assisted-cyberattack/5311103)).
:::

::: details **Drupal** : under certain conditions, the installer left on the server lets an attacker reinstall a site and take it over.
The critical flaw CVE-2026-132165 targets `/core/install.php`, which is not blocked by default after installation. The exploitation conditions are uncommon. A proof of concept exists, but no attack has been reported ([The Hacker News](https://thehackernews.com/2026/11/drupal-patches-critical-installer-flaw.html)). Fixed versions:

- 11.4.13;
- 11.3.22;
- 10.6.22.

Blocking installation scripts after use remains good general practice.
:::

::: details **CNIL and Macif Vie** : a 5 million euro fine for storing passwords in plain text.
Nearly 1.8 million customer passwords were stored in plain text. A database of 1.3 million customers was reachable through an account shared by eight people. Nobody could tell who did what. Contact data was also kept for more than ten years ([Next](https://next.ink/268231/la-cnil-sanctionne-macif-vie-a-hauteur-de-5-millions-deuros-pour-des-mots-de-passe-en-clair/)). Best practice remains hashing with bcrypt, scrypt or Argon2, never MD5 or plain SHA-256.
:::

::: details **UK and Apple** : a tribunal forces the government to confirm its secret order targeting iCloud.
In 2025, the UK government reportedly ordered Apple to build a backdoor into encrypted iCloud backups. Apple refused and withdrew its Advanced Data Protection in the UK. The specialist tribunal now requires the government to confirm the order exists, a first according to the group Liberty. A hearing next year will decide which details become public ([TechCrunch](https://techcrunch.com/2026/11/19/u-k-government-forced-to-disclose-secret-apple-backdoor-order/)).
:::

### Embedded and systems

::: details **Waveshare ESP32-S31** : a 4.3-inch touchscreen board built around Espressif's new RISC-V microcontroller.

::: details **de:volt** : a free in-browser breadboard simulator with an open source TypeScript engine.
It needs no account and offers about 105 components, including the 555 timer. Arduino, micro:bit and RP2040 boards are programmable in MicroPython. It flags errors and burnt components, with a virtual oscilloscope and multimeter ([CNX Software](https://www.cnx-software.com/2026/11/18/web-based-breadboard-simulator-lets-you-build-circuits-fix-errors-and-monitor-designs-with-a-built-in-oscilloscope/)).

::: details **AMD and NVIDIA drivers** : Windows services write to the SSD constantly and speed up its wear.
With AMD Adrenalin 26.10.1 and 26.10.2, a service rewrote its own file about once per second, up to 56 GB a day. AMD fixed it in driver 26.11.1, released on November 12. On NVIDIA, since driver 621.14, a service keeps rewriting a log file, at 3 to 45 MB/s according to Next's measurements. NVIDIA has not officially acknowledged the issue ([Next](https://next.ink/268322/a-cause-dun-bug-les-pilotes-amd-et-nvidia-ecrivent-constamment-sur-le-disque/)).

## Analysis

For a PHP and PostgreSQL stack, the day calls for concrete maintenance: a PHP update on one side, the new PostgreSQL 19 tools on the other. phpAfterShell shows that deserializing session data is still an attack vector. It is also the second wave of PHP fixes in a month.

The supply chain of AI tooling is the other key point. The hijacked agent-framework package targeted CI tokens, and 27 uncensored models showed signs of malicious code. It remains to be seen how many machines installed versions 1.26.1 and 1.26.2, and whether Artex's role in the attack on the European Commission will be confirmed.

PostgreSQL 19 features such as ON CONFLICT DO SELECT and WAIT FOR LSN apply to the kind of architecture behind [NEXUS](/nexus), Melchior JORDA's self-hosted assistant, which runs on PostgreSQL and Fastify.
