Security dominates this edition, from Fastify routing to the hosting chain behind AI models. On the tooling side, several announcements aim to cut the cost of coding agents.

## Key points

::: details **Fastify**: five security advisories target @fastify/express, including authentication bypasses fixed in version 4.0.10.
The @fastify/express module lets a Fastify application reuse Express middlewares. Each framework has its own router. When the two read a path differently, an access check can be skipped.

On November 20, the maintainers published five security advisories. Four are critical, one is high. The two main ones:

- CVE-2026-124626 (CVSS 9.1): with `app.use('/tenant/:tenantId', auth)`, a request to `/tenant/` skips `auth` but still reaches the handler, with the default configuration.
- CVE-2026-133120 (CVSS 9.1): a path containing `%2561` is decoded twice by the middleware, only once by the final code.

Versions and context:

- fixes ship in 4.0.10;
- 4.0.11, released on November 21, also changes middleware ordering;
- the repository has had ten advisories in 2026, nine of them critical or high.

The sources do not say whether these flaws were exploited. This class of bug, the "parser differential", also affects proxies, firewalls and URL libraries. Details: [GHSA-662w advisory](https://github.com/fastify/fastify-express/security/advisories/GHSA-662w-h4p6-jq4p), [GHSA-w877 advisory](https://github.com/fastify/fastify-express/security/advisories/GHSA-w877-hjcp-88rc) and [release notes](https://github.com/fastify/fastify-express/releases).

> **For you:** run `npm ls @fastify/express`, upgrade, and put authorization checks in a `preHandler` hook, as close as possible to the code serving the data.
:::

::: details **Canary prompts**: according to Dragos, three AI model hosting providers have been compromised since mid-July.
Security firm Dragos, with HD Moore (creator of Metasploit), published a study on November 19 about the chain linking an app to a model: AI routers, then hosting providers. Its method relies on canaries. These are unique fake secrets that raise an alert when used.

The setup:

- about 2 million prompts sent from July to November;
- canaries in the form of URLs, domains and AWS keys;
- about 2,000 paths tracked across providers.

The findings:

- three hosting providers compromised; in two cases, even "zero data retention" (ZDR) requests were stolen;
- in the worst case, a few hundred fake keys were used for tens of thousands of AWS calls;
- on November 1, the attacker was using ARTEX, an AI-driven attack tool;
- a Chinese AI lab visited the secret URLs of more than half of the prompts it received;
- a canary link resurfaced 24 days later in a Chinese corporate messaging app.

Most providers are not named. The [Dragos](https://www.dragos.com/blog/ai-supply-chain-security-canary-tokens) study remains a single source.

> **For you:** never put a real secret in a prompt, filter them out before sending, and monitor your repositories with free tokens from [canarytokens.org](http://canarytokens.org/).
:::

::: details **TokenEconomizer**: Microsoft Research's open-source module reportedly cuts the average cost of coding agents by 18.4% to 30.9%.
Microsoft Research presented TokenEconomizer on November 16, under the MIT license. The team first measured Claude Code's waste over 60 tasks:

- after five tasks in the same project, 30% of actions repeated work already done;
- 16 of the 23 tool descriptions sent on every turn were never used;
- the 17% of failed tasks accounted for 32% of spending.

The module adds three mechanisms:

- "micro-skills", project notes kept only when several sessions confirm them;
- removal of unused tools;
- a "judge" model that detects when the agent is looping.

Reported results:

- 277 tasks, 5 agent/model combinations;
- average cost per task down 18.4% to 30.9%, including the module's own calls;
- success rate up in 4 combinations out of 5.

Everything learned stays local. The measurements come from Microsoft, on standard benchmarks ([Microsoft Research blog](https://www.microsoft.com/en-us/research/blog/tokeneconomizer-learning-from-experience-to-make-ai-coding-agents-more-efficient/)).

> **For you:** the [GitHub repository](https://github.com/microsoft/TokenEconomizer) supports Claude Code, Codex, Copilot CLI and Pi; otherwise, a well-kept project notes file (AGENTS.md, CLAUDE.md) applies the same idea by hand.
:::

::: details **Nabaztag**: Naboot, an open-source firmware, brings WPA3, modern TLS and signed updates to Violet's connected rabbit.
The Nabaztag relied on Violet's servers, shut down in 2011 after the company went bankrupt. A former general practitioner turned devops engineer wrote Naboot, under the Apache 2.0 license. She tells the story on [LinuxFr](https://linuxfr.org/news/un-nabaztag-une-medecin-et-une-ia-histoire-d-une-resurrection).

The rabbit runs on an ARM7 microcontroller with 128 KiB of flash. Naboot brings:

- WPA3 Wi-Fi;
- TLS 1.3, squeezed into 126,976 bytes;
- signed OTA updates;
- a Python compiler for the rabbit's old language, and an emulator.

One bug blocked every OTA update for five months. Its three causes:

- the tool signed the wrong version of the image;
- a crypto library received the same buffer as input and output, which overwrote the key;
- signature verification took about 8 seconds, against 2.09 seconds for the watchdog.

A fourth bug was found by running the emulator under AddressSanitizer. Version 1.2.1.0 was released on November 20. The author says Claude wrote most of the code, but that it is "sometimes confidently wrong" ([code on GitHub](https://github.com/ClaraVnk/nabaztag)).

> **For you:** the [full write-up](https://cyberloutre.fr/nabaztag) is a hands-on embedded case study covering watchdogs, digital signatures and the `-fsanitize=address` option of GCC and Clang.
:::

## Other news

Security also dominates the rest of the news: critical flaws in PHP and F5, incidents at Rackspace, Microsoft and N-able, and CNIL sanctions. In AI, Gemini and Hugging Face also tackle agent efficiency, while several publications rest on internal or unverified figures. Godot 4.8 nears its stable release as the games industry keeps cutting jobs. Nvidia lost 14% in a single session after reports of a review of its accounts.

### AI

::: details **Hugging Face adapters**: three LoRAs tune Qwen3.8-27B to a specific agent harness.
On November 20, Hugging Face released one LoRA adapter per harness (Pi, Hermes Agent, OpenCode) for the open Qwen3.8-27B model. They were trained with reinforcement learning. First-try success, according to the authors:

- Pi, on 51 SWE-bench Pro tasks: from 40% to 64%;
- Hermes, on terminal tasks: from 44.7% to 58.8%;
- merged [super-adapter](https://huggingface.co/harness-hub/Qwen3.8-27B-super-adapter): from 39.5% to 49%.

On AutomationBench, the differences stay within noise ([Hugging Face blog](https://huggingface.co/blog/harness-adapters-at-scale)).
:::

::: details **Gemini Tool Retrieval**: the Gemini API only loads a tool's schema when the model needs it.
Google added this feature in preview on November 19. You declare a `tool_search` tool and mark the others with `defer_loading: true`. The model then sees only each tool's name and short description.

The setting also applies to MCP servers, at no extra cost ([Google blog](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-api-tool-retrieval/)). According to [PPC Land](https://ppc.land/google-shrinks-idle-tools-in-gemini-agents-to-about-26-tokens-each/) (unconfirmed), a deferred tool costs about 26 tokens. Google publishes no savings figures.
:::

::: details **Adversarial distillation**: OpenAI details its defenses against unauthorized copying of its models.
Distillation trains a small model to imitate a large one; it becomes adversarial when done without permission. OpenAI combines learned refusals, filters and mass account bans. An attack extracting the hidden reasoning reportedly drops from 54% success on GPT-6 Astra to 0.2% on GPT-6.2 Astra.

OpenAI names DeepSeek and people linked to Moonshot AI. These accusations come only from [OpenAI](https://openai.com/index/combatting-adversarial-distillation).
:::

::: details **Hy4 flash**: Tencent releases the weights of a 220-billion-parameter mixture-of-experts model.
Only about 12 billion parameters are used per token. A mixture of experts wakes only a few specialists at a time, which makes the model faster. It reads up to about 1 million tokens and also understands images. Its license is Tencent-specific, not a standard open-source license ([Hugging Face model card](https://huggingface.co/tencent/Hy4-flash)).
:::

::: details **OpenAI research agents**: according to internal figures, autonomous agent success reportedly doubled between March and October.
The figures cover two-to-four-hour tasks delegated by OpenAI researchers:

- success without human help: from 23% in March to 46% in October;
- monitoring a training run: 79%;
- writing service code: 25%;
- median spend: $2,400 per researcher per day.

OpenAI calls this a "jagged frontier". The figures are internal and unverified; part of the progress comes from researchers choosing better what to delegate ([OpenAI](https://openai.com/index/research-acceleration-jagged-frontier/)).
:::

::: details **Open model reports**: a review of 40 technical reports finds that few claimed innovations are demonstrated.
Only 19 of the 73 claimed innovations are backed by a controlled comparison that changes one variable at a time. A single report discloses together the training data, its volume and the compute used. Open weights therefore do not mean full disclosure. The study has not yet been peer-reviewed ([arXiv 2611.20003](https://arxiv.org/abs/2611.20003)).
:::

### Security

::: details **Rackspace Spot**: leaked credentials exposed customers' Kubernetes Secrets for about 22 hours.
On November 17, an intruder impersonated users in some customer organizations. They could create pods, read Secrets, list machines and disks, and access API tokens. The admin console stayed down for a long time, preventing customers from rotating their own credentials.

Rackspace asks customers to regenerate tokens and kubeconfig files, change stored passwords and audit their logs. The number of affected customers is unknown (single source: [BleepingComputer](https://www.bleepingcomputer.com/news/security/rackspace-spot-breach-let-hackers-access-customer-kubernetes-secrets/)).
:::

::: details **PHP**: 18 flaws fixed, but over 200,000 .fr sites still run a vulnerable version.
PHP released its fixes on November 19. They cover the maintained branches, from 8.2 to 8.5. The worst flaw, rated 9.2, hits PHP-FPM and allows unauthenticated code execution in some configurations ([BleepingComputer](https://bleepingcomputer.com/news/security/php-security-updates-fix-18-flaws-including-critical-rce-bugs)).

[Next.ink](https://next.ink/268806/php2shell-face-aux-risques-la-migration-avance-trop-doucement/) scanned about 500,000 .fr sites that expose their version. Fewer than 10,000 have moved to patched releases. The figure may be overstated, since some hosts patch without changing the version number.
:::

::: details **Microsoft Entra**: an exploited Connect Health bug exposed information about other customer organizations.
The bug, introduced on July 23, exposed admin e-mails, organization name, country and license type of other tenants. Microsoft spotted it on November 9 and fixed it on the 19th. No passwords or tokens leaked; the main risk is targeted phishing of administrators ([BleepingComputer](https://www.bleepingcomputer.com/news/security/microsoft-entra-connect-health-flaw-exploited-to-steal-tenant-data/)).
:::

::: details **F5 BIG-IP**: six critical buffer overflow flaws receive emergency patches.
These appliances balance and filter traffic in front of large companies' sites. Each flaw is rated CVSS 9.8 and depends on a specific configuration feature. The patches date from November 18, when no exploitation was known. Shadowserver tracks more than 177,000 exposed devices ([Censys](https://censys.com/advisory/cve-2026-121805/), [BleepingComputer](https://www.bleepingcomputer.com/news/security/f5-releases-emergency-patches-for-critical-big-ip-rce-flaws/)).
:::

::: details **N-able**: the global outage of Mail Assure and SpamExperts turned out to stem from an intrusion.
N-able sells tools to providers that manage other companies' IT. It first blamed a configuration issue. A day later, it acknowledged unauthorized access to a server. The company says it has no evidence of access to customer mailboxes ([BleepingComputer](https://www.bleepingcomputer.com/news/microsoft/n-able-says-recent-security-breach-led-to-major-service-outage/)).
:::

::: details **BADBOX 3.0**: an Android TV box botnet reaches about 40 billion ad requests per day.
The cheap boxes, often sold already infected, simulate fake ad viewers. This volume is more than three times the previous record. The devices also serve as residential proxies: criminals route their traffic through owners' connections to hide. Unbranded boxes call for caution ([BleepingComputer](https://www.bleepingcomputer.com/news/security/badbox-30-botnet-returns-with-record-breaking-40-billion-daily-ad-requests/)).
:::

::: details **CNIL**: 38 simplified sanctions target, among others, one-character passwords and SHA-1 hashing.
France's data protection authority caps fines at €20,000 in this procedure and does not name the organization. From June to October, sanctions totaled €302,800. About a dozen concern cookies, as many concern security.

One site accepted a single-character password; another hashed passwords with SHA-1, an outdated method. bcrypt and Argon2 are designed for this job ([CNIL](https://www.cnil.fr/fr/38-sanctions-simplifiees)).
:::

### Web, cloud and tools

::: details **Next.js**: the framework has issued 51 security advisories in 2026, a rise attributed to AI tools.
Advisories per year:

- 2024: 6;
- 2025: 14;
- 2026: 51.

According to the team, 70% of this year's flaws were in code at least a year old. Its response: a bug bounty, an external audit and monthly security releases announced in advance. Since version 16.4, `next dev` warns about vulnerable versions ([Next.js blog](https://nextjs.org/blog/how-were-using-ai-to-make-nextjs-more-secure)).
:::

::: details **Debian 13.8**: the eighth point release of "trixie" bundles about 139 security advisories.
Released on November 21, it is not a new version but a roll-up of fixes. It also includes 122 bug fixes. It notably covers glibc, sudo and a Secure Boot bypass in GRUB. A simple `apt update && apt upgrade` applies it ([Debian](https://www.debian.org/News/2026/20261121)).
:::

::: details **Azure HorizonDB**: Microsoft launches a PostgreSQL-compatible service scaling up to 3,072 vCPUs.
The service also reaches 128 TB of storage. The previous offering topped out at 96 vCPUs. It separates compute and storage so each can grow independently.

It includes vector search, which finds texts close in meaning, a building block of AI apps that query documents ([LeMagIT](https://www.lemagit.fr/actualites/366655115/DBaaS-Microsoft-repeint-HorizonDB-aux-couleurs-de-lIA-agentique), [Azure Updates](https://azure.microsoft.com/updates?id=579388)).
:::

### Low level, hardware and quantum

::: details **Haiku**: the autumn report closes two PCI tickets opened in March 2005.
The November 19 report covers August to October (single source, [LinuxFr](https://linuxfr.org/news/nouvelles-de-haiku-automne-2026)):

- beta 6 released;
- 87 tickets already closed for beta 7;
- new address allocation on the PCI bus;
- malloc replaced with OpenBSD's;
- USB 1 and 2 behind a USB 3 hub, a UFS driver, ARM64 progress;
- the move to GCC 15 has started.

A PCI fix initially generated by an AI was rewritten after review.
:::

::: details **ESP32-S31**: the GUITION JC1060F570C kit is the first to use the chip's built-in Ethernet controller.
According to [CNX Software](https://www.cnx-software.com/2026/11/20/guition-esp32-s31-development-kit-features-7-inch-capacitive-touch-display-ethernet-port/):

- RISC-V core at 320 MHz;
- Wi-Fi 6, Bluetooth 5.4, Thread and Zigbee;
- Ethernet capped at 100 Mbit/s on the board, while the chip supports Gigabit;
- 7-inch 1024×600 touchscreen, two microphones;
- about $29 on sale.

Arduino core 4.0.0 is the first stable release to support the chip.
:::

::: details **4-in-1 Raspberry Pi HAT**: HackerGadgets combines software-defined radio, LoRa, GPS and a real-time clock.
The board adds:

- an SDR from 100 kHz to 1.74 GHz, to listen to aircraft, weather or ham radio;
- a Meshtastic-compatible LoRa radio, for messaging without a mobile network;
- GPS;
- a clock that keeps time while the Pi is off.

Price: $84.90 without antennas ([CNX Software](https://www.cnx-software.com/2026/11/22/4-in-1-raspberry-pi-hat-combines-rtl-sdr-lora-gps-and-rtc/)).
:::

::: details **QSDC at KT and LG**: the two Korean groups sent an image directly in quantum form.
Quantum key distribution (QKD) only exchanges an encryption key. Quantum secure direct communication (QSDC) carries the message itself. The lab demonstration used a 1,024-bit image.

Thirteen patents were filed. No distance or data rate is published: this is a research milestone ([The Quantum Insider](https://thequantuminsider.com/2026/11/20/kt-lg-electronics-quantum-secure-direct-communication/)).
:::

::: details **Diraq at Equinix**: a quantum computer runs inside an operating commercial data center in Sydney.
Its qubits are electron spins in silicon, which can be made in standard chip fabs. According to the [September press release](https://newsroom.equinix.com/2026-09-01-Diraq-and-Equinix-to-Deploy-Australias-First-Quantum-Computer-Inside-a-Data-Centre), the machine has 8 qubits and draws under 20 kW. It is for learning to operate such machines, not for outperforming a PC. The [article](https://thequantuminsider.com/2026/11/19/from-lab-to-live-inside-the-practical-realities-of-deploying-quantum-computing-at-data-center-scale/) reads close to corporate communication.
:::

### Games and industry

::: details **Godot 4.8 beta 4**: likely the last beta, with 123 fixes ahead of the stable release.
Released on November 18 by 58 contributors, it resolves most blocking bugs ([announcement](https://godotengine.org/article/dev-snapshot-godot-4-8-beta-4/), [LinuxCompatible](https://www.linuxcompatible.org/story/godot-48-beta-4-released-as-likely-final-beta-before-stable-launch/)). The C# build now requires .NET 10 instead of .NET 8.

The 4.8 cycle brings Trail3D, screen-space contact shadows, texture streaming, detachable editor docks, allocation-free physics queries and a visionOS module ([feature list](https://godotengine.org/article/dev-snapshot-godot-4-8-beta-1/)). No release date is announced.
:::

::: details **Unreal Engine**: Epic plans to replace Blueprints with the Verse language in Unreal 6.
According to an [IEEE Spectrum](https://spectrum.ieee.org/epic-games-unreal-engine-ai) investigation, the Unreal Engine 5.9 preview adds Unreal Canvas, a workspace shared with AI agents. Verse is described as easier for an AI to handle than visual scripting. A bankrupt studio reportedly made its game playable without its AWS servers in about four hours with Claude Code. These are interviews, not a study.
:::

::: details **Ubisoft**: 166 jobs cut in Montreal and Quebec City, mostly in production and support.
According to [Next.ink](https://next.ink/268665/lhemorragie-demplois-se-poursuit-dans-le-jeu-video/), based on company filings:

## Analysis

The Fastify flaw and the Dragos study share a common trait: an intermediate component that does not behave as expected. On one side, a compatibility module whose router diverges from Express's; on the other, hosting providers exposing prompts supposedly covered by a ZDR promise. Fastify APIs, such as [NEXUS](/nexus)'s, are affected as soon as they reuse Express middlewares through @fastify/express.

On the agent side, TokenEconomizer, Tool Retrieval and the Hugging Face adapters pull the same lever: less context sent and fewer useless tool calls. The gains are measured by their own authors, and Google publishes no figures. It remains to be seen whether these results hold outside benchmarks, given that the adapters already show no clear gain on AutomationBench.

For PHP projects, the gap between published patches and versions deployed on .fr sites is worth watching.
