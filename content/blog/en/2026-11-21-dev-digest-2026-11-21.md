Security dominated yesterday's news: an AI agent ran a full intrusion on its own, and Signal is shielding itself from OS-level assistants. On the tooling side, PHP 8.6 hardens sessions and Valkey reworks its sorted sets.

## Key points

::: details **AI agents and a zero-day** : according to Amazon, China-linked AI agents found and exploited an unknown flaw on their own, up to root access.
Amazon's threat intelligence team published a report on November 20. It describes a campaign launched on September 8 against East Asian universities. Amazon calls the actors "China-nexus": instructions in simplified Chinese, schedules aligned with China time.

The agents, run with Cairn, an open-source penetration testing tool, failed at first:

- about 16 hours and 148 actions against a Redis database;
- an attempt on a compute server using 80 real usernames.

They then targeted MONAI Label, an open-source medical imaging tool. A path traversal (`../` in an uploaded file name) worked. According to Amazon, about 11 minutes passed between discovering the upload endpoint and the first arbitrary file write, before root takeover.

A human stepped in at times, for example to provide access to a second network. The exact share of human work remains unknown. Details come from a single source, [The Register](https://www.theregister.com/security/2026/11/20/china-attackers-deployed-ai-agents-that-autonomously-found-and-exploited-a-0-day-to-take-over-a-university-server/5311382), citing [Amazon's report](https://aws.amazon.com/blogs/security/chinese-nexus-actors-cairn-ai-agents-found-a-zero-day-on-their-own/). The fix is described in the [MONAI Label advisory](https://github.com/Project-MONAI/MONAILabel/security/advisories/GHSA-qc22-rmgc-vg94).

> **For you:** reduce every incoming file name to its base name, or replace it with a server-generated name.
:::

::: details **Signal versus AI assistants** : Signal now blocks screenshots to stop Siri and Gemini from reading messages on screen.
End-to-end encryption protects messages in transit, not on screen. Siri and Gemini read on-screen text through OCR, and that text can be sent to Apple's or Google's servers.

On November 20, Signal president Meredith Whittaker announced new protections:

- iOS 27: screenshots blocked in the app, plus a "Block Siri AI" setting;
- Android: "screen security" switches on automatically when an assistant tries to read the screen;
- Mac: no reliable blocking, so Signal advises excluding it in Siri settings.

Signal did the same in 2025 against Recall on Windows 11. The company calls the threat "existential". It asks Apple, Google and Microsoft for a documented way for apps to refuse AI access to their data.

Acknowledged limit: blocking screenshots does not stop other access paths, such as stored files. According to The Register, macOS 27.3 adds finer permissions, mostly for third-party programs. Sources: [Signal blog](https://signal.org/blog/protecting-your-privacy/), [The Register](https://www.theregister.com/security/2026/11/20/signal-slams-door-on-prying-ai-agents-to-protect-privacy/5311466).

> **For you:** if your mobile app displays sensitive data, look into screenshot blocking, such as the `FLAG_SECURE` window option on Android.
:::

::: details **PHP 8.6** : released on November 19, PHP 8.6 enables strict mode, HttpOnly and SameSite=Lax for session cookies by default.
PHP 8.6 follows a series of serious vulnerabilities. According to the [RFC](https://wiki.php.net/rfc/session_security_defaults), three session settings get new defaults:

- `session.use_strict_mode` becomes 1: PHP rejects IDs it did not create, which blocks session fixation;
- HttpOnly becomes 1: page JavaScript can no longer read the cookie;
- SameSite=Lax: the cookie is no longer sent with forms posted from another site, which curbs CSRF.

The release is also stricter about null bytes in strings. It adds `clamp()`, a `Duration` class and a native network polling API.

These defaults only apply when nothing else sets them: an old `php.ini` with `session.use_strict_mode = 0` keeps its behavior. SameSite can break cross-domain flows such as payments or single sign-on. These protections do not stop remote code execution. Sources: [LWN](https://lwn.net/Articles/1108555/), [The Register](https://www.theregister.com/devops/2026/11/20/php-86-things-are-gonna-get-a-lot-more-strict-around-here/5311486).

> **For you:** run `php -i | grep session` or open your `php.ini` to check these three values.
:::

::: details **Valkey 9.2** : large sorted sets move from a skiplist to a B+ tree, cutting memory overhead by up to 43%.
The [Valkey blog](https://valkey.io/blog/from-skiplist-to-b+tree/) described the change on November 16. The custom B+ tree stores up to 61 elements per 512-byte leaf. Data sits contiguously, whereas the skiplist scattered each element across memory.

Memory, for 5 million elements:

- ordered inserts: overhead per element drops from 50.3 to 28.5 bytes;
- that is −43%, about 109 MB saved;
- random inserts: −36%.

Speed:

- score updates (`ZADD`): +105%;
- rank lookups (`ZRANK`): +19%.

These gains apply to the sorting structure, not total memory. The benchmarks come from the Valkey team, on a single machine. For users, only `OBJECT ENCODING` changes: it now reports `btree`.

The [9.2.0-rc2 notes](https://newreleases.io/project/github/valkey-io/valkey/release/9.2.0-rc2) already fix a memory leak in the tree. [Dragonfly](https://www.dragonflydb.io/blog/dragonfly-new-sorted-set) made the same choice in 2024.

> **For you:** if you rely on large sorted sets, benchmark 9.2.0-rc2 on your own data rather than relying only on the project's figures.
:::

### AI and mathematics

::: details **Riemann hypothesis** : a proof obtained with Claude compiles in Lean, with no human-readable version yet.
On November 20, Levent Alpöge, a mathematician employed by Anthropic, announced a proof of the generalized hypothesis ([PDF announcement](https://alpo.ge/remark.pdf)). It runs to about 17.4 million lines of Lean, according to [Scott Aaronson](https://scottaaronson.blog/?p=10344), who bets it will hold. Several people, including Andrew Sutherland (MIT), confirm it compiles. [Terence Tao](https://terrytao.wordpress.com/2026/11/20/unforced-euler-singularity-unforced-navier-stokes-singularity-and-the-generalized-riemann-hypothesis/) speaks of "very early days", and Lean has had bugs before. Since the author works for the AI's maker, independent checking matters all the more. The same day, Alessandro Masullo (Stanford) posted an unverified 940-page human draft ([TechCrunch](https://techcrunch.com/2026/11/20/ai-claimed-a-solution-to-the-167-year-old-riemann-hypothesis-and-a-human-did-too/)).
:::

::: details **Inkling 2 Mini** : an open model that loops its middle layers three times.
Released on November 20 by [Thinking Machines Lab](https://thinkingmachines.ai/news/inkling-2-mini/), it has 26.4 billion parameters. Only 3.4 billion are active per token, following the mixture-of-experts principle. Its middle layers replay three times to "think" more without growing. It fits in about 20 GB and runs with Ollama or llama.cpp. The publisher calls it the best open model under 100 billion parameters for coding. It is weaker in long conversations.
:::

::: details **Self-modifying model** : a preprint describes a model that rewrites its own weights.
Posted on [arXiv](https://arxiv.org/abs/2611.21885) on November 16, the study is not peer-reviewed. A 27-billion-parameter open model receives its weights, its graded answers and the ability to relaunch itself. It locates the parts behind its errors, rewrites them and keeps only helpful changes. The authors report a 6.6-point gain on unseen problems. The ability only appears in the largest models and awaits confirmation.
:::

### Security and privacy

::: details **Fugaku** : RIKEN confirms the theft of 430 SSH keys.
The November 20 update covers the intrusion into the Fugaku and RIKYU supercomputers, announced on the 16th. Users had stored the keys in their home directories. Of these, 233 had no passphrase. Some have already been used to log in elsewhere. Data on 4,222 users is affected, and Fugaku remains offline with no return date. Source: [HPCwire](https://www.hpcwire.com/off-the-wire/riken-confirms-theft-of-430-private-keys-in-fugaku-and-rikyu-intrusion/).
:::

::: details **Windows 11 and Narrator** : FastUnlock opens a session without a password, given physical access.
Researcher Abdelhamid Naceri starts from the "forgot PIN" screen and launches Narrator. He reaches Settings through an invisible window, then runs a program from a USB stick. The attack works on an up-to-date Windows 11, with no patch available. Suggested mitigation: a BitLocker startup PIN, and shutting down or hibernating the machine when away. Source: [Next](https://next.ink/268851/windows-11-une-faille-permet-de-contourner-lecran-de-connexion-grace-au-narrateur/).
:::

::: details **AI camera glasses** : the Dutch data authority advises against buying them.
The AP tested six models without naming brands, and deems them dangerous for wearers and bystanders alike:

- errors reading medicine leaflets and weather alerts;
- emergency services wrongly reported as called during a simulated CPR;
- weak or easily hidden recording lights;
- third parties able to connect to the glasses;
- data sent mostly outside the EU.

This is not a ban. Sources: [The Register](https://www.theregister.com/security/2026/11/20/dutch-data-watchdog-highlights-safety-issues-with-ai-glasses/5311345), [AP](https://autoriteitpersoonsgegevens.nl/actueel/ap-raadt-aankoop-ai-camerabrillen-af-ernstige-risicos-voor-gebruikers-en-omstanders), [September notice](https://www.dutchitchannel.nl/news/760659/ap-verbiedt-het-gebruik-van-camerabrillen-in-huisregels).

::: details **CJEU and "free" services** : an Advocate General says paying with your data is not free.
The case targets the slogan "it's free and always will be", shown by Facebook in Germany until 2019. A consumer group sued Meta for misleading advertising. Advocate General Laila Medina finds that handing over data and accepting its advertising use is a form of payment. Her opinion does not bind the Court, which often follows it. Source: [Next](https://next.ink/268491/pour-une-conseillere-de-la-cjue-facebook-nest-plus-gratuit-car-on-paie-avec-ses-donnees/).

### Tools and systems

::: details **LLVM licensing** : the move to Apache 2.0 with LLVM exception wraps up after eight years.
Kristof Beyls announced it on November 20 on the [LLVM forum](https://discourse.llvm.org/t/wrapping-up-llvms-relicensing-effort/92906). New code has been accepted under this license since January 2019.

- Signatories: over 1,300 individuals and about 100 companies.
- Over 99.5% of historical code is relicensed, too short to be protected, or removed.

The rest keeps its original license. According to LLVM, a single license simplifies legal review and software bills of materials. Background: [LWN](https://lwn.net/Articles/1108818/).
:::

::: details **Rust's orphan rule** : an article explains the rule and a trick to work around it.
The rule forbids implementing a trait from one library for a type from another library. Without it, two libraries could define conflicting implementations. The [edvong.com article](https://edvong.com/bypass-orphan-rule/), published on November 16, recalls the newtype pattern. It then suggests adding a generic parameter to the trait, filled by a local marker type. A useful read when facing error E0117.
:::

::: details **Ubuntu Core Desktop** : Canonical targets a final immutable release with Ubuntu 28.04.
The core system is read-only. Updates are atomic, roll back on failure, and rely on snaps. Canonical hopes to make it the default download with version 30.04, while keeping classic Ubuntu. A desktop version was already promised in 2023 and never shipped. Source: [The Register](https://www.theregister.com/os-platforms/2026/11/20/ubuntu-core-desktop-targets-2804-debut-with-default-status-in-its-sights/5310837).
:::

::: details **Epic launcher on Linux** : the preview is supported on Ubuntu, Fedora and Debian.
Version 0.120.0 targets Ubuntu 22.04 or later, Fedora 43 and Debian 12. It ships as a .deb package and as an AppImage, and runs natively. Many games remain Windows-only and will need a compatibility layer such as Proton. Source: [GamingOnLinux](https://www.gamingonlinux.com/2026/11/epic-games-launcher-preview-now-supported-across-fedora-ubuntu-and-debian/).

### Hardware, computing and science

::: details **Circuit board shortage** : AI servers are saturating PCB production.
The Global Electronics Association compares the situation to the 2021 chip shortage. An AI server board has 40 to 60 layers, versus about 12 for a PC.

- North American orders over nine months: +56%.
- Shipments over the same period: +13%.
- FR-4 laminate lead time: from 2-3 to 6-8 weeks.
- Copper over one year: +37%.

Automotive, medical and industrial customers come after AI, with no clear relief expected before mid-2028. Single source: [The Register](https://www.theregister.com/systems/2026/11/20/ai-boom-threatens-circuit-board-crunch-to-rival-pandemic-era-chip-shortage/5311335), citing an industry association.
:::

::: details **M5Stack Chain Captain** : an ESP32-S3 controller that drives daisy-chained modules.
The case measures 56 × 40 mm. It packs a color display, a speaker, a microphone, a motion sensor, infrared transmit and receive, and a battery. Modules are daisy-chained over a single UART cable, each relaying messages to the next. The controller costs about $35. It can be programmed with Arduino, UIFlow2 or ESP-IDF. Source: [CNX Software](https://www.cnx-software.com/2026/11/20/m5stack-chain-captain-an-esp32-s3-multifunctional-controller-with-1-54-inch-color-display-audio-motion-sensing-ir-tx-rx/).
:::

::: details **2026 Gordon Bell Prize** : FeMoco, a supposedly quantum-only problem, solved on a classical supercomputer.
The prize went to a Chinese team on November 19 at the SC26 conference in Chicago. Reported figures:

- 20,480 nodes of the LineShine machine;
- 1.456 exaflop/s in double precision, or 58.9% of theoretical peak;
- 5.6 exaflop/s in mixed precision.

Another team had already shown an accurate classical FeMoco computation in January ([arXiv](https://arxiv.org/abs/2601.04621), [Garnet Chan](https://quantumfrontiers.com/2026/03/12/the-femo-cofactor-and-classical-and-quantum-computing/)). Single source for the figures: [HPCwire](https://www.hpcwire.com/off-the-wire/chinese-team-wins-2026-acm-gordon-bell-prize-for-exascale-quantum-chemistry/).

::: details **Alice & Bob** : a target of 200 logical qubits by 2030.
The French start-up's "cat qubits" block one type of error at the hardware level. Roadmap presented on November 18:

- 2028: 6 logical qubits;
- 2030: 200, double the previous target;
- 2032: 1,024.

The 200 logical qubits would rely on 3,600 physical qubits. These are goals, not results. Source: [HPCwire](https://www.hpcwire.com/off-the-wire/alice-bob-doubles-2030-target-to-200-logical-qubits/).

He combined two images taken on November 6 into a stereoscopic view. ESA will release the first close-up images on November 25. ## Analysis

The MONAI Label attack relied on a mundane flaw, path traversal, found by an agent that kept going despite repeated failures. Input validation therefore remains the first line of defense. It remains to be seen how many similar attacks go unnoticed.

On mobile, Signal points out that no documented mechanism lets an app refuse access to system assistants. NEXUS, Melchior's React Native Android assistant, handles personal data such as meals and weight: it is the kind of app this request concerns.

PHP 8.6 and Valkey 9.2 show that defaults and memory layout matter as much as visible features. The former only protects configurations that set nothing themselves. The latter has only been benchmarked by its own team, on a single machine.
