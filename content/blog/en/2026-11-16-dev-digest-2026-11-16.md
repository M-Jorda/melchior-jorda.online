Yesterday's news centred on a flaw in an AI inference engine, a critical MongoDB CVE and a new input format for language models. Embedded hardware, cloud pricing and computing history round out the roundup.

## Key points

::: details **SGLang and NEAR AI** : a remote code execution flaw in SGLang let an attacker break into NEAR AI's inference servers.
SGLang is an open-source inference engine: it runs a model on GPUs and answers requests. NEAR AI ran it inside a trusted execution environment (TEE), an area isolated by the processor.

An attacker exploited a remote code execution flaw in SGLang. Impact reported by NEAR AI:

- requests on one server exposed on the day of the attack;
- data from about 100 accounts;
- the history of 18 AI agents hosted outside the TEE.

NEAR AI draws the lesson itself: a TEE does not protect against a flaw in the software running inside it. The vulnerability has been reported to SGLang, with no CVE number so far. Details from [The Hacker News](https://thehackernews.com/2026/11/sglang-rce-exploit-breaches-near-ai.html) and in [NEAR AI's incident report](https://near.ai/blog/security-incident-report-sglang-vulnerability).

> **For you:** if you serve models with SGLang, watch for a patch and a CVE identifier.
:::

::: details **MongoDB CVE-2026-118383** : a flaw rated 9.5 out of 10 lets an unauthenticated attacker crash a server in a replica set.
MongoDB is often deployed as a replica set: several copies, one of them primary. If the primary goes down, another member is elected to replace it.

The flaw is a use-after-free: the program reuses memory that has already been freed, a classic C++ bug. The attack requires no account. The described scenario:

- the attacker sends two crafted `ping` commands;
- a lagging server is later elected primary;
- that server crashes before accepting writes.

No real-world exploitation is known. A proof-of-concept, however, is public. Source: [The Hacker News](https://thehackernews.com/2026/11/critical-pre-auth-mongodb-flaw-cve-2026.html).

> **For you:** update every member of your replica sets and restrict network access to your databases.
:::

::: details **IBM's LLMON** : a markup built on reserved tokens aims to stop models from confusing instructions with data, tested on two experimental Granite models.
Instructions and data are often passed to a language model as JSON. According to IBM, braces and quotes also appear in ordinary text, and the model sometimes confuses structure with content. That confusion opens the door to prompt injection, where crafted text poses as an instruction.

LLMON (pronounced "lemon") marks structure with special tokens that cannot appear in the data. What IBM releases and claims:

- two experimental Granite 4.1 models;
- on its own test, 47% more attacks blocked than the best large model tested;
- preview status, not meant for production.

The figure comes from a test designed by IBM. Source: [IBM's blog on Hugging Face](https://huggingface.co/blog/ibm-granite/llmon-an-llm-native-markup-language-now-in-granite).

> **For you:** try LLMON against your own prompt injection cases, but keep it out of production while it remains a preview.
:::

## Other news

Hardware dominates: an industrial PC for robots, an IP KVM, a homemade 486 handheld and a USB reverse-engineering tool. On the AI side, a small tool-calling model and an Apple health study stand out. The industry tracks the race for compute, from China's post-NVIDIA plans to the TOP500 expected at SC26. A disputed web redesign, UK regulation and LEO's 75th anniversary complete the list.

### AI

::: details **BotPsy** : Tether AI Research releases a 0.8-billion-parameter model specialised in tool calling.
Based on Qwen3.5, BotPsy decides when to call web search, a calendar or message sending, and with which arguments. On several tool-calling tests, it scores roughly double its base model. A compressed GGUF version is available for llama.cpp. Acknowledged limits: complex tasks, and 21% unsafe answers in automated attack tests. Apache 2.0 licence. Source: [QVAC blog on Hugging Face](https://huggingface.co/blog/qvac/botpsy).
:::

::: details **Apple Health AI Study** : Apple launches a US study app on using AI for health questions.
Since 15 November, the app answers questions based on medical journals (NEJM, JAMA, Nature), with the company OpenEvidence. Participants rate the answers and can share sleep or heart-rate data for personalised replies. The goal is up to 200,000 volunteers over 21, for more than a year. Apple says it anonymises the data and does not use it to train its models. Source: [TechCrunch](https://techcrunch.com/2026/11/15/apple-launches-new-app-to-study-how-people-use-ai-for-health/).
:::

::: details **Radxa Linkr** : a USB-stick-sized IP KVM, from $59, reviewed by CNX Software.
An IP KVM plugs into a computer's HDMI and USB ports so you can control it from a browser, BIOS included. Strengths: HTTPS, two-factor authentication, remote access via Tailscale. Weaknesses: initial setup over plain HTTP, an update that wiped all settings, and clipboard sharing that does not work yet. Source: [CNX Software](https://www.cnx-software.com/2026/11/15/radxa-linkr-review-a-compact-ip-kvm-with-https-2fa-authentication-and-tailscale-support/).

::: details **VapourDeck** : Sprite_tm builds a DOS gaming handheld around a real 486 processor.
The 486 is an Intel processor from 1989. Sprite_tm designed his own motherboard: a period VGA chip for display, an FPGA replacing the many glue-logic components, and an ESP32-S3 for sound. He chose the 486 partly because Intel's documentation from that era is public. The design files are open on Codeberg. Sources: [Hackaday](https://hackaday.com/2026/11/15/vapourdeck-is-the-486-handheld-you-didnt-know-you-needed/) and [the author's write-up](https://spritesmods.com/?art=vapourdeck).
:::

::: details **usb-rea** : an open-source tool that eases reverse engineering of USB devices to drive them on Linux.
Many peripherals only work with the vendor's Windows software. With usb-rea, by Emir Mrkaljević, you start a capture (on Linux via usbmon), annotate the action performed in the official software, then repeat with other values. The tool links each note to the packets sent. It then generates a report, a Python driver skeleton and a Wireshark dissector. Sources: [Hackaday](https://hackaday.com/2026/11/15/reverse-engineer-that-usb-device-in-style/) and [the usb-rea repository](https://github.com/emirmrkaljevic/usb-rea).
:::

::: details **LEO turns 75** : the first business computer ran its first program in 1951.
J. Lyons, a British tea-shop company, used it for calculations for its bakeries. LEO was based on Cambridge's EDSAC, one of the first stored-program computers: the program sits in memory alongside the data. Mary Coombs became the first commercial programmer there in 1952. Cambridge's Centre for Computing History celebrates the anniversary on 28 November. Source: [The Register](https://www.theregister.com/offbeat/2026/11/15/leo-gets-a-birthday-bash-75-years-after-clocking-in/5308806).

## Analysis

Two of the three key stories concern the layer that connects an application to a language model. The NEAR AI incident shows that TEE isolation leaves the risk of a flaw in the inference engine itself untouched. LLMON targets another link: the boundary between instructions and data in the model's input. It remains to be seen whether IBM's claimed results, measured on its own test, hold up beyond the preview.

The MongoDB flaw is a reminder that C++ memory bugs also affect databases, and that here no account is needed to attack. On the web side, the Humble Bundle redesign shows that a security feature such as two-factor authentication can disappear during an update.

For a self-hosted assistant like [NEXUS](/nexus), whose Fastify API relies on Gemini or Claude, separating instructions from user data is one of the questions LLMON raises.
