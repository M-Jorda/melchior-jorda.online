This digest is dominated by security: a key leaked by a coding agent at Together AI, then two code execution flaws, in Ghostscript and in binary-parser. On the language side, C++26 is done again after a non-unanimous international vote.

## Key points

::: details **Together AI**: a coding agent pushed a secret key to GitHub, and samples of customer prompts were stolen.
Together AI, an inference provider, published its [incident report](https://www.together.ai/blog/security-event-prompt-leakage-for-requests-in-june-and-july-of-2026). The company kept samples of customer prompts for testing, in a private Hugging Face repository. During development, a coding agent committed an access key to that repository into a public GitHub repository.

- Affected requests: mostly from June 24 and July 4, 8 and 14, 2026.
- An automated scan caught the key and the commit was reverted, but it had already been grabbed.
- The attacker searched the samples for other credentials, then tested them.
- Five of them were canaries planted by Dragos: fake secrets that raise an alert when used.

Together discloses neither the number of affected customers nor the exposure window. The investigation continues with law enforcement and an outside firm. The company promises short-lived keys, a scan of every change and zero data retention (ZDR) by default.

On November 22, [OpenRouter](https://openrouter.ai/blog/announcements/data-processing-incidents-on-inference-providers/) dropped three providers. It also removed the ZDR label from 125 endpoints.

> **For you:** revoke any committed key immediately, even after reverting, and run coding agents' commits through the same secret checks (GitHub push protection, gitleaks) as human ones.
:::

::: details **Ghostscript**: the Upload2Shell flaw lets an attacker run commands on a server from a simple uploaded file.
On November 21, researchers at [pwn.ai](https://pwn.ai/upload2shell/research.html) detailed CVE-2026-125396, found with help from an OpenAI model. A font-loading function performed a privileged write without checking its data. A crafted font lets an attacker control memory, disable file checks and run commands, while the -dSAFER sandbox stays enabled.

The entry point is an upload. ImageMagick or Pillow can hand Ghostscript a file with a "safe" extension that actually contains PostScript. The attack worked on ten products, including:

- Debian 13 network printing, via an anonymous print job;
- the Roundcube webmail, just by opening an email;
- WordPress with some plugins, MediaWiki and DokuWiki.

The fix shipped in Ghostscript 10.08.0 on September 8. According to [BleepingComputer](https://www.bleepingcomputer.com/news/security/ghostscript-flaw-lets-hackers-hijack-servers-via-pdf-uploads/), Debian 12, Amazon Linux and some SUSE versions were still unpatched as of November 12. The score is 8.5 under CVSS 4.0 and 7.8 in other databases, because the flaw is rated "local" even though it was exploited remotely (see also the [Red Hat entry](https://bugzilla.redhat.com/show_bug.cgi?id=2569593)).

> **For you:** on any server that thumbnails user uploads, check the version with gs --version and block the PS and PDF formats in ImageMagick's policy.xml if you do not need them.
:::

::: details **binary-parser**: before version 2.3.1, this npm library inserted unchecked options into the JavaScript code it generates.
binary-parser decodes binary data from a description. For speed, it generates tailored JavaScript code once, then runs it. CVE-2026-134814 comes from several options (length, key, offset, among others) being pasted as-is into that code.

An attacker who controls the description can therefore run their own JavaScript on the server. According to the maintainer, decoding hostile data with a developer-written description remains safe. Affected applications are those where users describe a format themselves: protocol analysis tools, IoT platforms.

- The fix only accepts simple names, such as foo or $parent.len.
- An expression like len - 1 must now be passed as a function.
- The flaw stems from an incomplete fix of CVE-2026-1245, rated 6.5 and patched in January.
- The new one gets two scores depending on the scale: 9.2 and 8.1.

This comes from a single source, [The Hacker News](https://thehackernews.com/2026/11/critical-binary-parser-flaw-enables.html), which relies on the [maintainer's advisory](https://github.com/advisories/GHSA-xmxc-6c22-m377).

> **For you:** run npm ls binary-parser and then npm audit in your Node.js projects, and treat any eval or new Function fed with external data with suspicion.
:::

::: details **C++26**: the standard is done again, after the first non-unanimous national vote in C++ history.
Five countries voted against the final draft (DIS) because of contracts. Contracts state in code what a function requires and what it guarantees. Meeting in Búzios, Brazil, with about 220 participants, the committee kept them, according to the [trip report by Herb Sutter](https://herbsutter.com/2026/11/21/c26-is-done-again-trip-report-november-2026-iso-c-standards-meeting-buzios-brazil/), its chair.

- Vote: 111 for, 9 against, 8 abstentions, or 92.5%.
- Support in February 2025: 87.7%.
- Support in March 2026: 90.5%.

One criticism is that a contract can be checked or ignored depending on how the code is compiled. The committee added an option to mark a contract as "always checked", which partly addresses it. A second national vote must follow, then publication, with no set date; the opposing countries and their objections are not known.

C++26 also brings reflection and std::execution ([Wikipedia](https://en.wikipedia.org/wiki/C%2B%2B26)). Already adopted for C++29:

- the 0o prefix for octal (today, 010 equals 8);
- named break and continue;
- std::ranges::any_view.

> **For you:** compile with -std=c++26 and check [cppreference.com](http://cppreference.com/) to see which features your compiler already supports.
:::

## Other news

Security stays in front, with CrowdStrike's bid for Zscaler, a critical ScreenConnect flaw and ransomware at the Guadeloupe university hospital. In AI, several figures rest on a single source or a non-peer-reviewed study: robots driven by general-purpose models, a large model on a consumer GPU, the effect of agents on junior hiring. Microsoft is reshuffling its tools, bundling PowerShell 7 with Windows and retiring To Do. European regulation and principles for AI in schools round things out.

### Security

::: details **CrowdStrike and Zscaler**: an all-stock acquisition valued at about $43.9 billion.
Announced on November 23 ([SEC filing](https://www.sec.gov/Archives/edgar/data/0001535527/000153552726000035/crwd-20261123xex991.htm), [Next](https://next.ink/brief-article/crowdstrike-va-racheter-zscaler-pour-44-milliards-de-dollars/)). Each Zscaler share will be worth 1.135 CrowdStrike shares. The deal combines endpoint protection (EDR) with cloud-delivered network security (SASE).

- Over $10 billion in combined annual recurring revenue.
- About 2,000 shared customers.
- Closing expected between mid-2027 and January 2028.

CrowdStrike cites AI agents. It remains to be seen how competition authorities will respond.
:::

::: details **ScreenConnect**: a flaw rated 9.9 turns the remote support tool against technicians.
With CVE-2026-84869, a fake customer sends a file that the technician's software runs silently. According to Huntress, the attack takes about 9 seconds and plants a hidden backdoor on a machine that often holds every client's credentials. Huntress saw at least 688,000 attempts across 42 servers, between October 20 and November 16. Fix: version 26.6.5 or later ([The Hacker News](https://thehackernews.com/2026/11/hackers-exploit-critical-screenconnect.html)).
:::

::: details **Guadeloupe hospital**: ransomware has paralyzed the hospital, reached through an IT contractor.
The attack happened on the evening of Saturday, November 21, triggering the hospital's emergency plan. Staff are working without computers or phones. Surgeries, imaging and non-urgent appointments are postponed until November 27. According to the hospital and ANSSI, the attackers came in through an unnamed contractor that had itself been breached months earlier ([Next](https://next.ink/brief-article/le-chu-de-guadeloupe-est-paralyse-par-une-cyberattaque/)).
:::

### AI

::: details **RoboChallenge Zero**: eleven general-purpose models drive real robots, with a 44.85% average success rate.
Published on November 23, the test evaluates models without task-specific training, over 330 trials.

- GPT-6.2 Astra: 70%; Claude Fable 5.2: 66.7%.
- Placing the largest blocks: 89%; writing "Z0": 7%.
- Untangling a cable: no success.
- A simple task: 13 to 14 minutes, about 500,000 tokens.

Single source, five trials per task, robots not named ([QbitAI, in Chinese](https://www.qbitai.com/2026/11/511978.html)).
:::

::: details **Linger**: Simplex AI claims a 125-billion-parameter model running on an RTX 3060.
This open-source personal agent comes from Simplex AI, founded by a former DeepSeek engineer. Its engine spreads the experts of an MoE model: the most used in GPU memory, others in RAM, the rarest on SSD. Claimed speed: 45 tokens per second. Setup: a 12 GB RTX 3060 with 64 GB of RAM. Figures not independently verified, single source ([QbitAI, in Chinese](https://www.qbitai.com/2026/11/511570.html)).
:::

::: details **AI agents and jobs**: a non-peer-reviewed study links their use to fewer non-senior job postings.
Four economists cross about 2 quadrillion tokens of real usage with 34.8 million postings from US listed companies ([arXiv](https://arxiv.org/abs/2611.27210)). For a typical usage gap:

- posting growth is 2.1% lower over six months;
- 3.2% lower over nine months.

Senior roles are not affected, and simple AI use (chat, summaries) has no measurable effect. It is a working paper: a correlation, not proof of cause.
:::

::: details **Apple**: the 27.3 betas cap AI features that run on Apple's servers.
This covers complex Siri queries, some photo edits and use by third-party apps. The daily quota resets at midnight; on-device features stay unlimited. A bigger iCloud+ plan multiplies the quota:

- ×2 with 200 GB (€2.99/month);
- up to ×20 with 12 TB (€59.99/month).

Apple does not say how large the base quota is ([Next](https://next.ink/brief-article/apple-limite-lusage-de-son-ia-et-vend-des-quotas-plus-eleves-avec-icloud/)).
:::

::: details **Quantum error correction**: a $12 million Harvard-led project bets on AI.
The ASQC project is funded by the US Department of Energy. It aims to use AI to tailor error-correction codes and decoders to each scientific problem: chemistry, materials, nuclear physics. Partners: three national labs, MIT, Cornell, QuEra, NVIDIA and Anthropic. The goal: fewer qubits for reliable results ([The Quantum Insider](https://thequantuminsider.com/2026/11/23/quera-12-million-doe-ai-quantum-error-correction), [QuEra press release](https://www.prnewswire.com/news-releases/quera-computing-joins-harvard-led-12-million-doe-project-to-design-ai-driven-error-correction-for-fault-tolerant-quantum-computing-302948510.html)).
:::

### Tools and platforms

[Next](https://next.ink/269400/powershell-7-va-integrer-windows-les-entreprises-vont-devoir-verifier-sa-compatibilite/) points to version 27H2, in the second half of 2027. - errors from external programs handled differently;

::: details **ESPHome 2026.11**: ESP32 boards can now connect through a 4G modem.

It lays the groundwork for signed over-the-air updates, which will reject firmware of unknown origin. It uses less memory. Several changes break older configurations.

### Games and 3D

::: details **CORTAO**: the ambient occlusion technique seen in EVE: Frontier is now open source.
Daniel Isheden, of Fenris Creations, published CORTAO [on GitHub](https://github.com/theagentd/CORTAO). Classic SSAO approximates occlusion from the rendered image. CORTAO traces rays through the image for a more accurate estimate over a wider area, and converges faster according to [Game Developer](https://www.gamedeveloper.com/programming/devs-can-now-utilize-high-end-ambient-occlusion-technique-seen-in-eve-frontier). Two years of work, with no performance figures published.
:::

::: details **3D movies on Quest**: Meta rents and sells over 150 films in the US, streaming only.
Since November 19, the Quest TV app offers rentals at $6.99. A "purchase" is a streaming license with no download, valid as long as Meta holds the rights. Meta has already shut down two VR movie stores, in 2018 and 2020, refunding customers ([VR.org](https://vr.org/articles/this-week-in-vr-2026-11-20), [Variety](https://variety.com/2026/digital/news/meta-3d-movies-rent-buy-quest-vr-headsets-1236953488/)).
:::

### Industry and regulation

::: details **DMA**: BEUC denounces "cosmetic" compliance by the big platforms.
Report published on November 17 ([BEUC](https://www.beuc.eu/news/where-six-big-tech-gatekeepers-are-likely-not-be-compliant-digital-markets-act), [Next](https://next.ink/269443/dma-la-conformite-de-facade-des-geants-du-numerique-epinglee-par-le-beuc/)).

::: details **AI in schools**: data protection authorities adopt eleven principles.
The Global Privacy Assembly resolution puts the child's best interest first ([CNIL](https://www.cnil.fr/fr/gpa-ia-education)). It calls for privacy by design, limited data retention and transparency. An AI must not decide a grade or an educational path on its own. The text includes a model charter for schools.

He resigned on November 12, after reports of extramarital affairs. On November 23, the board unanimously reinstated him. He says senior US officials told him his return poses no national security risk; Donald Trump had publicly called for it. Investigations continue, and a reported SEC probe remains unconfirmed ([Game Developer](https://www.gamedeveloper.com/business/nvidia-reinstates-jensen-huang-as-ceo), [Next](https://next.ink/269365/nvidia-reinstalle-jensen-huang-a-son-poste-de-ceo/)).

## Analysis

The three security incidents in the key points share one trait: the risk comes from an indirect link. Ghostscript is called by ImageMagick or Pillow, binary-parser runs code it generates itself, and Together AI's key was committed by a coding agent. For a Node.js or PHP stack, auditing dependencies and secrets therefore has to cover what tools do on the developer's behalf.

Patch propagation remains something to watch: Ghostscript 10.08.0 dates from September, and major distributions were still unpatched in mid-November. On the C++ side, it remains to be seen whether the second national vote will approve contracts.

[NEXUS](/nexus), Melchior JORDA's self-hosted assistant, matches the setup described by the Together AI incident: a Fastify API sending requests to Gemini or Claude. OpenRouter removing the ZDR label from 125 endpoints shows that prompt non-retention has to be verified rather than assumed.
